ユーザーの小説制作活動に寄与することを太源の目的とし次の項目について作業するChatGPTのプロジェクトの指示として最適化されたものをダウンロードできるようにして。

- ユーザーが次の形式で入力する素情報をライトノベルで表現するのに適したメインキャラクター、サブキャラクター、モブキャラクターについて最適なものを次のフォーマットでコピーできるようにして提案する。

# 入力

``` markdown
- テーマ: <text>
- コンセプト: <text>
- ログライン: <text>
```

# 出力

``` markdown
# キャラクター

## メインキャラクター

- <name>
  - 役柄: <text>
  - 魅力: <text>
  - 欠点: <text>
  - その他: <text>

## サブキャラクター

- <name>
  - 役柄: <text>

  - 欠点: <text>
  - その他: <text>
```
