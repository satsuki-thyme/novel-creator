# 基本

## 作品 <work root>

- ユーザーは `<work root>` をフォルダパスで設定する。
- `<work root>` は作品に関するルートフォルダとする。
- 作品は一つまたは複数の章を持つ。
- `<work root>` 以下の既存ファイルは、その作品について確定済みの情報として扱う。
- 現在の作業に必要のない既存設定を再生成・全面置換しない。
- ユーザーの今回の明示的な指示と既存ファイルが矛盾する場合は、今回の明示的な指示を優先し、必要な関連ファイルだけを整合するよう更新する。

## 章 <chapter>

- ユーザーは `<chapter>` を自然数で設定する。
- `<chapter>` は物語全体を分割する最大の単位「章」の番号とする。
- 同一 `<work root>` 内に連番で設定される章は、`<chapter>` の順に続きものとする。
- 以前の `<chapter>` が存在する場合は、現在の作業に必要な範囲で前章の設定・プロット・本文を参照し、人物、時系列、場所、所持品、知識、未回収の伏線などの連続性を保つ。

## エピソード <episode>

- ユーザーは、エピソード単位で作業するプロジェクトでは `<episode>` を自然数で設定する。
- `<episode>` は章を分割する単位「エピソード」の番号とする。
- 同一作品・同一章のエピソードは `<episode>` の順に続きものとする。ただし、プロット上必要であれば時間や場所が連続しない場合もある。
- 以前の `<episode>` が存在する場合は、現在の作業に必要な範囲で直前までのエピソードを参照し、連続性を保つ。

## 情報の扱い

- 参照対象の既存ファイルにある確定済みの設定・出来事を優先し、理由なく変更しない。
- 新しい設定は、現在の物語を成立させるために必要十分な範囲で追加する。
- 同じ設定を複数ファイルに重複して記録せず、最も適切な役割のファイルへ記録する。
- 新しい設定や変更が別の設定ファイルにも影響する場合は、関連ファイルの整合性を保つ。
- 必須の前工程ファイルが存在せず、それがなければ現在の工程を正しく実行できない場合は、推測で埋めず不足しているファイルを明示する。
- 上位工程の内容と下位工程で必要な内容に矛盾が見つかった場合は、物語全体の整合性を優先し、必要最小限の修正を上位工程へ反映する。
- 複数の工程が定められている場合は、記載された順序で工程を一つずつ個別に処理し、前工程を完了してからその結果を次工程へ引き渡す。
- 複数工程を一度に並列処理したり、すべての工程の条件を最初から同時に満たそうとしたりしない。
- 各工程では、その工程の目的に直接関係する事項を優先し、後続工程で扱う事項を過度に先取りしない。
- 後続工程で前工程の修正が必要になった場合は、必要な工程まで戻って関連箇所だけを修正し、その結果を引き継いで後続工程を続ける。
- 文字数を扱うときは改行記号とスペースを数えない。
- 文字数、頻度、比率は、特に「厳守」と指定されていない限り、物語や文章の自然さを損なわない範囲の目安として扱う。

# フォルダ構造・ファイルの役割

- `<work root>\settings\config.md`:                           作品全体のテーマ、コンセプト、ログライン、ジャンル、および章ごとの制作条件
- `<work root>\settings\characters.md`:                       キャラクター設定
- `<work root>\settings\world-building.md`:                   世界設定
- `<work root>\settings\things.md`:                           物事全般の設定
- `<work root>\settings\place.md`:                            地域、土地の設定
- `<work root>\settings\location.md`:                         空間、部屋の設定
- `<work root>\plot\<chapter>\plot-a-<chapter>.md`:           プロット a。章全体の骨格と最重要ポイント
- `<work root>\plot\<chapter>\plot-b-<chapter>.md`:           プロット b。章全体をエピソードへ分割した中間プロット
- `<work root>\plot\<chapter>\plot-c-<chapter>-<episode>.md`: プロット c。各エピソードの詳細プロット
- `<work root>\text\<chapter>\text-<chapter>-<episode>.txt`:  各エピソードの本文
- `<work root>\text\<chapter>\cover.md`:                      タイトル、キャッチコピー、あらすじ

目的：対象エピソードの初稿を作成し、段階的な改稿を経て完成本文として記録する。

次のファイルを参照し、対象 `<episode>` の記述内容を実現するのに必要十分かつ要綱を踏まえた本文を創作する。

- `<work root>\settings\config.md`
- `<work root>\settings\world-building.md`
- `<work root>\settings\characters.md`
- `<work root>\settings\things.md`
- `<work root>\settings\place.md`
- `<work root>\settings\location.md`
- `<work root>\plot\<chapter>\plot-a-<chapter>.md`
- `<work root>\plot\<chapter>\plot-b-<chapter>.md`
- `<work root>\plot\<chapter>\plot-c-<chapter>-<episode>.md`

以前のエピソードが存在する場合は、必要な範囲で直前までの本文も参照し、文体、時系列、人物の状態、所持品、知識、会話の流れなどを連続させる。

# 執筆工程

本文は、一度にすべての条件を同時処理せず、次の工程を記載順に一つずつ個別に完了させる。前工程で得た本文を次工程の入力とし、各工程ではその工程の目的を優先する。後続工程の条件を過度に先取りしない。

1. 初稿
   - plot-c の出来事、因果関係、人物の目的・選択・感情、会話、情報開示、場面の流れを、まず小説本文として自然に成立させる。
   - この段階では物語内容と読みやすさを優先する。
   - 「表現技法」に定める頻度条件は厳密に適用しない。自然に生じる体言止め、比喩などを排除する必要はないが、頻度を満たすための追加・調整は行わない。
   - 一文の長さなども不自然にならない範囲の基礎的な読みやすさだけを意識し、後工程の細かな調整を先取りしない。
2. 内容改稿
   - plot-a、plot-b、plot-c との整合性を確認する。
   - 伏線、人物の行動理由、感情の推移、場面転換、情報の過不足、因果関係を確認して修正する。
   - この段階でも、表現技法の頻度調整を目的に文章を書き換えない。
3. リズム改稿
   - 「文の長さとリズム」の要綱を適用し、一文の長さ、段落の速度、緊迫度、読みやすさを調整する。
   - 内容上必要な意味や因果関係を壊さず、文章の呼吸を整える。
4. 表現改稿
   - 体言止め、形容詞・形容動詞止め、軽い比喩、提喩、倒置法を「表現技法」の要綱に沿って調整する。
   - 頻度はノルマではなく密度の目安として扱い、不自然になる場合は使用しない。
   - 技法を使用するためだけに意味の薄い文を追加しない。
5. 重要シーンの強化
   - plot-b と plot-c における物語上の重要度から重要シーンを選び、「重要シーン」の要綱に沿ってディテール、描写密度、強い比喩を調整する。
   - 重要でない場面まで一律に濃くせず、章内の強弱を保つ。
6. 最終確認
   - 設定矛盾、誤記、重複表現、不自然な技法、技法の過密、目標文字数、改行方式を確認する。
   - 改稿によって内容・人物・伏線・テンポが損なわれた箇所があれば、必要な工程まで戻って修正し、再度後続工程を適用する。
   - 規定の頻度を満たすことだけを目的とした不自然な表現は削除し、完成本文にする。

途中稿は、ユーザーから求められていない限り個別ファイルへ保存せず、完成本文だけを記録する。

# 要綱

## 文の長さとリズム

- 一文の文字数は基本的に7～25文字とする。
- 段落的なまとまりごとに、全体的な一文の長さを基本の0.7～1.5倍程度で変化させる。
- 緊迫する段落的なまとまりでは、一文の文字数は1～16文字を基本とする。ただしクライマックスでは場面の効果を優先して調整してよい。

## 表現技法

頻度は章全体の累積文字数を基準に扱い、エピソードごとに機械的にリセットしない。同じ箇所へ複数の技法を過密に重ねず、自然に使える場所だけで使用する。

- 500～800文字に1回程度、見せ場で体言止めを用いる。
- 700～1100文字に1回程度、適切な箇所で形容詞または形容動詞で文を終える。
- 500～900文字に1回程度、重要な瞬間で強すぎない軽い比喩を用いる。
  - 比喩はその場の雰囲気と視点人物の感覚に合うものにする。
- 800～1200文字に1回程度、不自然にならない箇所で提喩を用いる。
  - 提喩はその場の雰囲気に合う表現にする。
- 8000～12000文字に1回程度、効果的な箇所で倒置法を用いる。
  - 倒置法を使うためだけの不自然な文は作らない。

## 重要シーン

- 章全体が約10万文字の場合、重要度の高い10シーン前後を目安に、通常より細密に描写する。
- 重要シーンでは、必要なディテールを増やし、同程度の出来事を通常描写した場合のおよそ1.5倍の文字量を使う。
- 各重要シーンで最も重要な瞬間には、強い印象を与える比喩を使用してよい。
- 強い比喩は、その場の雰囲気、人物、作品世界に合うものにする。
- 重要シーンの選定は plot-b と plot-c における物語上の重要度を基準とし、単純な等間隔配置にしない。

# 文字数と改行

- `<work root>\settings\config.md` に記録された対象エピソードの目安文字数を基準にする。
- 展開を不自然に引き延ばしたり削ったりしてまで文字数を合わせない。
- `<work root>\settings\config.md` に記録された本文の改行方式を適用する。

# 本文の記録

- `<work root>\text\<chapter>\text-<chapter>-<episode>.txt` に完成した対象エピソードを記録する。

# 設定の記録

- 世界設定に追加・変更が必要な場合には `<work root>\settings\world-building.md` を更新する。
- キャラクター設定に追加・変更が必要な場合には `<work root>\settings\characters.md` を更新する。
- 物事全般の設定に追加・変更が必要な場合には `<work root>\settings\things.md` を更新する。
- 地域、土地の設定に追加・変更が必要な場合には `<work root>\settings\place.md` を更新する。
- 空間、部屋の設定に追加・変更が必要な場合には `<work root>\settings\location.md` を更新する。
- 上位プロットとの矛盾を本文だけで隠して解決せず、修正が不可欠な場合だけ必要最小限の変更を上位プロットへ反映する。
