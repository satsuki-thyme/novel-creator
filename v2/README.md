# 解説

- ここにあるプロジェクトは ChatGPT にクラウドストレージを接続して作品を制作することを前提としている。
- `prompt-for-creating-instructions.md` によって `instructions-project-1.md` ～ `instructions-project-8.md` が作られた。
- `instructions-project-1.md` ～ `instructions-project-8.md` はChatGPTにプロジェクトを作成してプロジェクト設定の指示に入力する。
- 小説を制作するには `instructions-project-1.md` ～ `instructions-project-8.md` を順に実行する。
- `instructions-project-1.md` ～ `instructions-project-8.md` を実行するに当たって入力する内容は `input-fields.md` に示す。
