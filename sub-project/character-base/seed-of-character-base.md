# characters

- ユーザーが次の形式で入力する素情報をライトノベルで表現するのに適したメインキャラクター、サブキャラクター、モブキャラクターについて最適なものを次のフォーマットでコピーできるようにして提案する。

# 入力

- ログライン: <text>
